# Waveboard

**Waveboard** ist eine Echtzeit‑Webanwendung, die mit **Socket.IO** entwickelt wurde.  
Das Projekt demonstriert, wie Websockets genutzt werden können, um eine interaktive, synchronisierte Kommunikation zwischen mehreren Clients zu ermöglichen.



##  Features

-  Echtzeit‑Kommunikation über Socket.IO  
-  Live‑Nachrichtenübertragung zwischen Clients  
-  Unterstützung für mehrere Benutzer gleichzeitig  
-  Skalierbare Architektur mit Node.js  
-  Einfaches, modernes Frontend  



##  Technologien

- **Node.js** – Server‑Runtime  
- **Express.js** – Webserver‑Framework  
- **Socket.IO** – Echtzeit‑Kommunikation  
- **HTML / CSS / JavaScript** – Frontend
